# Wallet · Motion study

Самостоятельный интерактивный концепт по референсам Telegram iOS.

## Локальный запуск

Из этой папки:

```sh
python3 -m http.server 5188 --bind 127.0.0.1 --directory dist
```

Открыть http://127.0.0.1:5188/. Внешние зависимости не нужны.

## Сценарии

- Отправка → поиск контакта → сумма → TON/USDT → подтверждение.
- Проверка доступного остатка и точности до двух знаков.
- Изменение тестового баланса и история операций до перезагрузки страницы.
- Просмотр актива, скрытие баланса, светлая/тёмная тема, сброс демо.
- Пополнение и обмен показывают честную заглушку, ведущую к готовому сценарию отправки.
- Клавиатура: Tab, Shift+Tab, Escape. Поддерживается reduced motion.

Все контакты, суммы и графики демонстрационные. Сетевых операций с деньгами нет.

## Референсы

- https://ilyagrshn.com/wallet_animations/ — каталог компонентов, динамические панели и Apple presentation.
- https://www.figma.com/design/kZ0nrTYMZzUX2IgltQPkQu/Telegram-IOS-UI-Kit--Community-?node-id=6016-11367 — Community UI kit. Просмотрена страница General и получен design context для Grouped Table View 6802:5770 (акцент #008BFF, 17/22 px, радиус 26 px).

Это авторская адаптация на HTML/CSS/JS, не официальный продукт Telegram и не подключённый пакет библиотеки. Официальный статус первого референса не подтверждён.

Файлы прототипа и конфигурация Sites изолированы от основного портфолио.
